# D103CN fault descriptions

The numeric `2/2` fault property is specified as a byte without a value list in the D103CN MIOT specification. The descriptions in `D103CNErrorDescriptions.json` are Dreame family descriptions, not individually verified D103CN diagnoses. The number is displayed alongside every description; missing and unknown codes stay unknown. Some codes may describe features absent on this model. Error descriptions do not alter the existing control checks or dock-reminder handling.

The table was derived from the `DreameVacuumErrorCode`, `ERROR_CODE_TO_ERROR_NAME` and English error descriptions in [Tasshack/dreame-vacuum](https://github.com/Tasshack/dreame-vacuum). Its MIT license is reproduced in `D103CNErrorDescriptions.LICENSE`. The model specification is available at [MIOT Spec](https://home.miot-spec.com/spec/xiaomi.vacuum.d103cn).
