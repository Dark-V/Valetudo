# Valetudo для Xiaomi Mijia M30S (D103CN)

Экспериментальный порт для локального управления. Проверенная **заводская прошивка: 4.5.6_1409**, Athena **r2405_release**, ARMv7.

> [!NOTE]
> **Почему появился этот форк**
>
> Я написал, что нашёл способ получить root на собственном пылесосе, и спросил, с чего лучше начать адаптацию Valetudo. После этого получил бан на 10 лет в сообществе исходного проекта.
>
> Я продолжил работу самостоятельно и опубликовал инструменты получения root для своего пылесоса и этот порт для D103CN.

> [!WARNING]
> Проект экспериментальный. Действуйте на свой страх и риск. Нет гарантии от повреждения устройства, потери настроек или окирпичивания. Храните бэкапы вне пылесоса, сохраняйте аварийный доступ по SSH/UART и заблокируйте устройству Интернет после открытия root/SSH.
