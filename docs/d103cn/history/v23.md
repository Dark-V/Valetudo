# v23: dock reminder and recharge-state diagnosis

Native code 114 is the upstream Dreame mop-tray maintenance reminder. It is now shown as a reminder rather than a fatal robot error when the robot is in a known stationary dock state and actually charging. The native code remains available in diagnostics; unexpected active-operation contexts and unrelated faults are not suppressed. Charging/full charge is explicit beside battery level. A drying counter of zero is treated as unavailable, without inventing a finishing/start time.

Reads native task-status (4/7) and breakpoint restart (4/11). Nonzero task status on idle/paused/returning/docked states uses the same resumable flag as upstream Dreame. This does not enable automatic resumption or send movement, charging, station or configuration actions.

Actual owner readback showed code 114, drying status 8, charging at 31-33 percent, task-status 0 and auto-resume disabled. Latest native history marked the job complete (68 minutes, 42 square metres); this proves the firmware is not currently advertising an unfinished task, not that every requested area was physically cleaned. Captured real-property parsing, type checks and lint passed. Deployment and rendered UI remain separate verification steps.
