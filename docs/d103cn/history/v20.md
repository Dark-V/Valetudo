# v20: native station actions and go-to

Adds standard Valetudo dock-action and go-to capabilities, reusing the existing Dreame encoders. D103CN wrappers perform fresh dock/fault, mop and component checks. Native attachment properties 4/53 (zero means installed) and 4/6 and dock components 27/1-3 are reported to the standard UI. Station requests are serialized and non-replayed.

Mop interaction uses action 4/4, piid 10: 2,1 wash, 1,0 wash stop, 3,1 dry, 3,0 dry stop. Dust collection uses 15/1. Go-to uses native mode 23 and tpoint, not zone cleaning. Saved-map-only, low battery and incompatible operation states are rejected. Real-device readback confirmed the required sensors; physical command verification is tracked separately until completed.

Scope continues in this order: station control, genuine go-to, cleaning history, persistent room profiles, Wi-Fi UI, then multiple maps if feasible. Water-hookup-kit functions and pixel editing are excluded from the mandatory scope.

## Owner-device verification
Native drying start/stop, mop washing start/stop, and one complete dust collection were confirmed from actual property transitions through the standard REST controls. No emulator was used. Go-to navigation remains physically unverified; further actuator tests were deferred after the owner was startled by the dock noise.
