# v19: visible station operations

The regular Dock card is shown when native station telemetry is present, even when manual dock-action capabilities are not registered. Robot status also describes active washing, drying and dust collection. Native drying remaining minutes (2/5) and progress (4/64) are displayed; active dust collection uses 15/5, not the availability property 15/3. Dock composition reuses the upstream Dreame maps.

State polling publishes its complete bounded batches together to avoid intermediate combinations. Manual control exposes readiness and an explanation before an incompatible operation is requested. Existing fault handling and deadman checks remain active.

The actual owner's drying telemetry was read and parsed: status 8, dock status 2, fault 68 as a charging mop reminder, 62 minutes remaining and 47 percent progress. No drying/washing/emptying job or robot movement was started for this check. TypeScript, lint and frontend build passed. Other station phases still require observation on actual hardware; no robot emulation was used.
