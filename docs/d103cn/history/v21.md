# v21: cleaning history from the stock database

Adds a read-only CleaningHistoryCapability and a paginated history table under Robot > Statistics. The existing factory sqlite3 CLI reads /data/config/ava/clean_log.db with -readonly and query_only; no new database, native library or executable is installed. Records expose original dates, cleaning minutes, area and completion, not inferred error causes. Dates use the clock that existed when the record was created. The reader bounds subprocess time/output, validates fields and pagination, coalesces requests and caches pages briefly. Errors do not disclose native database content.

This extends the port; it is not an existing upstream history capability. Historical maps are not included. The actual factory query returned three records before implementation. Type checking, lint, frontend build and real-device API/browser verification are recorded separately.
